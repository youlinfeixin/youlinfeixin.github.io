# 量子力学理论概述

自从作为量子理论第一创始人的普朗克为了解释黑体辐射问题于1900年提出能量量子化假说以来，已经过了一百多年，量子理论由最初的被科学界排斥，到后来被接受，直到目前广泛应用，其本身的发展存在着许多争论，因为量子理论能够很好的被实验所证实是正确的，但背后的思想却又无法被科学家们所接受，量子理论的发展，尤其是相关实验，对于科学家们而言，是一件彻头彻尾“毁三观”的存在。

虽然爱因斯坦通过普朗克量子化概念，成功解释了光电效应，因而获得了1921年的物理学诺贝尔奖，也被称为量子理论第二创始人，但是却对量子理论的主流派哥本哈根诠释无法认同，他的无法认同其实也正是代表绝大部分科学家的疑惑所在。爱因斯坦对哥本哈根诠释无法认同主要体现在量子诡异的瞬时作用（EPR佯谬，爱因斯坦-波多尔斯基-罗森佯谬），薛定谔为了支持爱因斯坦，才提出了著名的薛定谔的猫的思想实验，并对EPR佯谬中的量子鬼魅般的瞬时作用称之为“量子纠缠”。

EPR佯谬其实就是在试图通过经典物理学思想来论证量子理论中超时空特性的不完备性，即量子纠缠的“不合理性”，结果后来还真的被实验所证实，量子纠缠现象的确存在，量子之间的交互作用的确存在着某种不为科学家所知超时空作用。所谓佯谬，是相对悖论而言的，佯谬是说人们本以为错误的事，实验结果被证实是对的，悖论则相反，人们本以为是对的事情，结果被证实是错的。

虽然薛定谔推导出了薛定谔方程，但是他和爱因斯坦不一样，爱因斯坦接受能量量子化思想，只是不接受波恩（哥本哈根学派代表人物）对薛定谔方程的概率解释，而薛定谔本人对于代表量子化思想的基本的粒子轨道跃迁的思想都无法接受。波恩是数学家，通过对薛定谔方程的推导，及其敏锐的数学知识，成功地将“波函数”解释成了概率，成为了哥本哈根诠释的重要基础之一，而爱因斯坦对这种概率解释表示无法接受，通俗讲，波函数的坍缩表示一个粒子在特定区域内，一旦被观测，其某个特定位置存在的概率就瞬间变成了100%，或者0%，这种概率上瞬时的转换，这就好比一个房间中的两个人，把粒子比喻成一枚银币，那么一个人手中的硬币突然变没了，另一个人手中突然无缘无故多了一枚银币。爱因斯坦认为这是破坏“因果律”的，整个物理学乃至科学大厦就是建立在这种似乎永恒不变的“因果关系”之上的，有因才有果，科学家们才能够通过找寻“因”来预测或者定制“果”，或者通过控制背后的“因”来创造想要的“果”。

爱因斯坦的类似思想实验可以看出其疑虑所在，他认为鬼魅式量子纠缠，就好比一双球鞋，一只左脚鞋，一只右脚鞋，在无法观测的情况下，将其随机一只放到南极，另一只放北极，将其中任意一只打开观察的时候，知道了这只是右脚鞋，就立马知道了远在另一极的鞋子是左脚的，也就是说，在这双鞋子分开的那一刻，是左是右就已经确定了，也就是说粒子的相对属性在被观测之前就已经确定了，只是以某种不为人知的方式来确定的而已，爱因斯坦虽然不知道何种方式，但将其定义为“隐变量”。而做为哥本哈根诠释领头人的波尔则反对这种比喻，他认为如果把粒子的对称属性（如粒子自旋）比喻为左右脚的球鞋，那么在这双球鞋分开之后，在未被观测之前，南极的鞋子既是左脚又是右脚鞋，处于左与右的叠加态，只有在被观测之后，左还是右才被确定下来，并且南北极鞋子一只为左，另一只必然为右。

后来的进一步精确实验的确支持波尔的说法，并且发展出了量子的退相干理论，处于量子纠缠的叠加态，及其退相干理论成为了现代量子计算机技术的最基本的理论基础。

# 量子世界的因与果

爱因斯坦与波尔为量子理论，尤其是某些看似违反常理的概念而争论了近半个世纪，爱因斯坦认为哥本哈根诠释违反了因果律，波尔则说违反因果律就违反因果律，只是在量子微观领域不再适用而已，宏观的因果律依然存在，我们都知道宏观世界是由微观粒子构建的，咋能一个适用，一个又不适用了呢？

爱因斯坦著名的“上帝是不会掷骰子的”的言论就是在这种背景下提出来的，以此来表明，坚决捍卫因果律，而波尔对此回应道“请不要告诉上帝如何做”！爱因斯坦认为一切都有因有果，并提出隐变量的概念，科学家们先后也提出了十多种不同的隐变量模型，但是很难通过实验验证，后来通过英国物理学家贝尔推导出了经典物理学中严格成立的贝尔不等式，并以此为依据设计实验来试图证明爱因斯坦正确还是哥本哈根诠释派正确，由于实验需要大量的纠缠态的粒子，限于当时的技术限制，很难制备大量纠缠态粒子，直到后来爱因斯坦去世之后，才有多个实验室证明贝尔不等式与实验结果不符，证实爱因斯坦的隐变量假说不正确，哥本哈根诠释再得一分。

贝尔本来是爱因斯坦的支持者，提出贝尔不等式及其实验设计，本来是想证明爱因斯坦的正确性，结果像薛定谔为了支持爱因斯坦而定义了量子纠缠的概念，以及薛定谔的猫的思想实验，结果都帮了倒忙，（量子纠缠的概念已经成了现代量子理论的基本概念，薛定谔的猫也成为了量子理论入门的经典案例），二人被后人戏称为“成功将球踢进自家球门的队员”。

至此，量子理论虽然不符合常理，也无法有一个令人信服的解释，但是哥本哈根诠释却非常符合实验结果，其推导出来的模型结果经得起实验数据的考验。因此，现代物理科学家对于量子理论流行“闭嘴，计算”的思想，对于量子力学违反因果律等常理的部分避而不谈，只是用理论来计算推导，进行量子计算机等的研发与应用。

所以在这种默契之下，科学家们接受了哥本哈根诠释，其基本思想包括：一个量子系统的量子态可以完全的由波函数来表述，量子系统的描述是概率性的，物质普遍存在波粒二象性，且不可同时表现出来，以及不确定性原理等。

爱因斯坦对于量子系统的概率性描述无法接受，因为这种概率性说明了某个粒子在某一时空可能存在，也可能不存在，这种可有可无的说法，谁能够接受？可有可无不就好比说可以当它不存在吗？

# 传统多世界诠释

哥本哈根诠释虽然非常符合实验数据，但是它也不是完美的理论，因为到底是什么导致波函数的塌缩，又是何时塌缩的物理解释没有，主要是数学模型上的解释而已。哥本哈根诠释无法给出波函数的物理意义上的解释。

为此1957年首次由埃弗莱特提出多世界（平行宇宙）诠释，简化了量子理论，薛定谔方程始终存在，只是波函数无需塌缩，避免了令人头痛的波函数塌缩物理意义解释，但由于该诠释方法太离奇开始没有人认真对待，直到后来平行宇宙的概念在诸多理论推导中是成立的，拥有理论存在基础，后来得到了越来越多人们的重视，成为了继哥本哈根诠释法之后的另一个流行的诠释方法。而且平行宇宙也解释了物质与反物质相对应的宇宙与反宇宙的多宇宙假说，因为现代科学家疑惑根据物质与反物质守恒，为什么我们的宇宙很少发现反物质，宇宙大爆炸必然产生等量的物质与反物质，那么多反物质去了哪里？科学家据此猜测，反物质可能就存在于另一个平行宇宙中。

有人说“在科学史上，多世界诠释无疑是目前所提出的最大胆、最野心勃勃的理论。”多世界诠释在理论方向上接近一体论思想体系，但是在具体诠释上需要进行修正。

以薛定谔的猫思想实验为例，埃弗莱特指出两只猫都是真实的。有一只活猫，有一只死猫，它们位于不同的世界中。问题并不在于盒子中的放射性原子是否衰变，而在于它既衰变又不衰变。当我们向盒子里看时，整个世界分裂成它自己的两个版本。这两个版本在其余的各个方面都是相同的。区别只是在于其中一个版本中，原子衰变了，猫死了；而在另一个版本中，原子没有衰变，猫还活着。”

反对多世界理论的人会反驳说：你哪儿有这么大的本事和面子，一观察就多了一个世界。理解的误区就是发生在这里。

# 一体论思想多世界观

经过一体论思想体系调整的多世界理论是这样的，“三生万物”即宇宙大爆炸以来，并不只是产生了一个宇宙，而是许多个平行宇宙，虽然众多，但是从绝对的观念来说并不是无限多个的，从有限的心智理解上来说，可以看似无限多个，如传统多世界诠释一样，在整体宏观上来说，它们之间只有非常细微的差别。也就是说，它们的产生并不是在所谓的“看”的那一刻，在我们“看”之前就存在了，因此，我们的“看”并不会导致一个新的平行宇宙的产生，所以，我们的“面子”不用决定世界的多寡，可以放下这个“思想包袱”。

如一体论大师佛陀所说，我们所在的世界本质上是“果相”，也就是说，这里并不存在绝对意义上的“因果律”，我们所谓的因果关系都只是相对的，而绝对的“因”存在于时空之外，即“三生万物”之前，“万物”即时空宇宙，根据一体论思想大师老子的“道生一、一生二、二生三、三生万物”的思路，绝对的“因”是超越“万物”之上的，即“形而上”的，“万物”存在的“因”是“三”，而“三”的因又是“二”，“二”的因又是“一”，直到绝对境界的“因”是“道”为止！

在后来的一系列的量子双缝干涉实验中，从简单的实验模型直到后来复杂的量子延迟擦除实验说明量子纠缠的确存在超时空属性，以及超越因果律的，因此出现了两个截然相反的思想派，一个认为宇宙万物是确定的，一切都已经发生了，我们只是身处一个写好的剧本的世界里而已，简称注定论；另一个认为我们的意识是可以改写物理现实的，物理现实随意识而变化，简称决定论。

这两派思想看似完全相反，也是人们唯一能够得出的两种结论，对于普通大众的体验上来说，我们似乎能够主导世界，又似乎不能主导世界，似乎处于这两种思想的纠缠态，这也是人们普遍对于人生观存在着不确定性，即二元性：有时自信，有时犹豫，有希望，又有挫折，有存在感，又没有存在意义等。

其实我们不必如此，在一体论思想体系中，还存在着第三种严格意义上的解释方式，这个解释将完善对量子理论中多世界诠释。那就是对于时空性（线性）的思维下，即狭义意识下，注定只能存于同一个世界状态下，同一个世界的一切都是确定的，不以人们的意识为转移的动机，我们打开盒子，观察薛定谔的猫时，看到它是活的，只因它在我们“身处”这个世界本是活的，如果看到死猫，只因我们“身处”死猫的这个版本世界。对于这个世界中要发生的一切，只要我们“身处”其中，那么一切都是确定的，如上述所说的第一种思想派，即注定论。

# 广义意识决定所处平行世界版本

那么这里“身处”怎么解释呢？简单来说，就是意识（这里的意识是指广义意识，参加《论广义意识与狭义意识》一文）所在之处，那么是什么决定意识应该存在于这个世界，而不是那个世界呢？或者说如何让意识在平行宇宙中转换呢？

基于一体论思想体系，宇宙在形成之初，就已经存在了许许多多个平行宇宙版本（并非无限），之间相差甚微，每一个宇宙中的物理法则与现实都已经确定，可以把所有宇宙比喻成同一部电影的不同版本，电影存在的要素就是“时间、空间、形体”，我们可以将不同版本的电影比喻成由“时间”、“空间”、“形体”不同元素混合产生出来的众多版本，我们能够想到，不能够想到的版本都在同一时刻就已经存在了。

对于一个“身处”世界的人来说，从理论上来说，我们只能在不同版本的电影中跳跃式的转变，什么样的意识或者思想才能够做到这一点呢？

根据绝对意义上的因果律，每个平行宇宙，即不同版本的电影都是“果”，那个“因”在超时空领域的“三、二、一、道”之中，如果要转变电影版本，就必须在“因”下工夫。

我们为何要转变电影版本，或者说在不同平行宇宙中跳跃呢？其中的现实与实践意义何在？我们太习惯通过意识来主导行为，并通过行为来改变世界了，但是我们如果不将意识提升到超时空境界，就无法真的改变世界，幻相之所以是幻相，就是我们看似以为我们正在改变世界，其实也真的只是以为如此而已，其实该发生的就是注定会发生，不会发生的，再怎么担忧，或再怎么努力，它也不会发生。一切都只是自己一厢情愿而已。

活出一体论思想，就是要通过一种类似于量子跳跃式的、非线性式的、超越时空属性的思想，通过转变这个超时空属性的思想/意识这个“因”，来改变这个“果相”，以在已存在的不同版本电影中切换。通过这种跳跃来“改变世界”，当然，说是改变世界，也只是说在已经存在的版本之间转变而已，在非一体性的“道”境界，无法实现真正意义上的改变。这就是对旧有“行为改造世界”的全新量子化思想诠释！

我们为什么不直接从“万物”的二元时空境界转变到“道”的一体境界就好了？代表“三”的二元性思想体系为什么要创造基于时间、空间、形体而存在的宇宙，而且还要一次性产生这么多个？它背后形成的动机是什么？等等，这些都是一体论思想体系需要解释的核心问题。

简单说来，我们以往习惯将世界看成是时间、空间、形体/物质的要素组合，这是狭义意识领域的看法，上升到广义意识领域，我们要将世界看成是“一体论思想”与“二元论思想”这两个思想的物象化混合产物，即世界是这两种抽象的混合思想的具体化象征而已。

我们不可能直接从二元论思想跳跃到一体论思想，因为一体论思想与二元论思想是非常截然相反的思想体系，这需要心灵的锻炼（灵修）才能逐步完成整个转变过程。如果把多版本的平行宇宙比喻成多版本的梦境，那么二元论思想体系必然导致的是“恶梦”，而一体论思想体系必然导致的是“美梦”，而凡是梦境者，必然会有觉醒的一刻，对于做恶梦者，必须先经由“美梦”，才不会突然被惊醒，遭受二次伤害。

之所以同时存在多重平行宇宙，是因为二元论思想无法创造永恒与无限的事物，永恒与无限只有存于一体性境界，时间、空间、形体原本是二元论思想用来分裂心灵的手段，如今它不得不用尽可能多的时空层面才能模仿它渴望的永恒与无限，但它不可能做到，最多只是一种“心灵觉醒”的拖延战术而已。因为“心灵的觉醒”意味着“二元论思想（小我）”的消亡。

基于时间、空间、形体元素存在的“万物”，就像只有画面与声音的电影，而心灵只是一个观影者，我们可以在内心用不同的思想去诠释我们所看到的画面与声音，心灵不可能是中立的，如果是的话，那么画面与声音只是毫无意义的乱码与噪音，如今我们认为画面与声音之所以有我们所认定的意义与解读，完全是因为我们早就有对其诠释的思想体系存在，归根结底，要么是一体论思想体系，要么就是二元论思想体系。

因此我们之所以认为他人有意识，完全是因为首先我们的心灵与世界中某个人物角色认同了，将心灵与身体建立了某种联系，然后又由于他人有与我们一样的物理行为，才会认定其他人也必然具有与我们一样的意识。未必如此！当耶稣说“让死人去埋葬死人”，是因为他看透了世界的虚幻不实的本质。一个人所具备的身体及其行为表现，并不足以表明它具有意识（心灵），而是因为有处于分裂状态的心灵的角色认同而已，至于为何认同，这又是一体论思想体系需要解答的一个核心问题。现代有科学家意识到了这个问题，我们所看到的其他人，从严格理论上来说，我们既无法证明他人与我们一样有意识，也无法证伪！

总之，多重平行宇宙及其中的人物角色，只是有如电影剧情中虚拟的角色一样，本来只是一位观影者的心灵，由于某种“角色认同”而与某个世界中的人物建立起了联系，基于这种认知，从理论上来说，我们可以通过修正思想而微调到不同版本的剧情中，这也是我们之所以能够在平行宇宙跳跃的理论基础。也是为什么不能随意评断任何人事物，因为因着自己的评断，才无法进行量子式的“多世界跳跃”，如此，我们所评断的这个世界将挥之不去，最终是自己的思想束缚了自己。于是，耶稣才会说“你们不要论断人，免得你们被论断”！

也正是因为耶稣知晓世界及其身体的虚幻本质，才会说：“凡是已认清这世界的人，必也看清了这具身体；凡是已看清这具身体的人，世界对他不再有任何价值。”（《多玛斯福音》：80）

于是，对于如何改变我们的存在境遇，就可以通过这种量子跳跃式、非线性思维去做出调整，而不是通过旧有线性思维模式去做，那样很可能只是“一厢情愿”，只是在同一个世界中按部就班的发展，基于一体论思想体系之量子跳跃式思维，通过转变思想体系，而在不同世界版本中跳跃式的进展，这种进展一般是以心智无法察觉的方式发生着！

关于“三生万物”的内在动机，这也是灵修的核心问题之一，唯有搞清楚了根本原因，才可能做出正确的修正，最后，修正心灵思想的，是神圣的灵性，即圣灵！它会根据对一体性（道）的记忆，结合时空形的存在层面，形成一体论思想体系，来逐步替换掉“二元论思想体系”！关于这一点不是本文讨论的主要问题，日后在“一体论思想之灵修基本原理”一文中具体深入讨论。

# 结语

科学家们主要将目光投入到“时间、空间、形体”层面，试图找寻宇宙的奥秘，这样的找寻并不能从根本上解决心灵层面的“内在冲突”，但是科学上的进展却可以为灵修/悟道者所用，通过超越“时空形”的思想体系，来帮助灵修者们发展出一条完备的灵修思想体系，即一体论思想体系。“万物”的存在，不论是宇宙还是人，是建立在二元论思想体系之上运作的，为了能够突破二元论思想体系的思想封锁，必须用“同等级的思想体系”来相制衡，这个思想体系非“一体论思想体系”莫属，不可能再有其他的思想体系了，一个导向分裂/毁灭，一个导向合一/重生。这是心灵解脱与觉醒（救赎与悟道）的根本之所在。本文主要提供一个灵修思想体系大体思路方向，无法面面俱到，有些更加详细的问题将在日后的《友林感悟》系列文章中分析。
